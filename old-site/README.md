# Previous Reserve Africa site

This is the site that was live before the October 2026 redesign. It is kept here unchanged so it can be restored.

To switch back, run from the repo root:

```sh
mkdir new-site && git mv index.html reserve-desk.html reserve-studio.html new-site/
git mv old-site/* .
```

(This also moves this README to the root; delete it or move it back.)
